# Issues

Sorted by impact. Each entry stays at three lines or fewer, gives its issuer count where known, and has its evidence in the commit that changed it. The investigation logs from before this reshape are in `git show 93ea13bb:plans/issues.md`. Remove an entry when it closes.

A recovery for a withheld value is built only after `bun run sweep:sec --diff` shows that the rule publishes at least one instant on the cache and moves no other published value.

Fix classes, not instances. Before fixing a Wrong-value class, add its invariant to `scripts/report-sweep.ts` (or a ledger check to `sweep:sec`) and note the count here; the fix is done when `bun run sweep:report --diff` shows the count at 0 and every other transition is explained. A finding from a new deep run is first checked against the sweep, to see whether it is one more instance of a listed class or a new one.

Recovery needs positive split-basis proof, e.g. the price source's split list against the count's filing date.
- **Annual periods with no filed diluted count are withheld** (9 periods: TAYD FY2023–26, GOOGL FY2018–19, GPN FY2016, INVZ FY2020–21); NI / diluted EPS no longer stands in.
- **A null close before the newest bar still rejects the whole split-adjusted history.** Only a null newest close is dropped (as an unverified session); an earlier one would shift scoring's session count. Seen once, in a `yahoo-verified-chart` payload (NBIS 2026-08-11, cache 2026-08-12) followed by an in-progress bar; recovering it needs a per-use rule, not a parser drop.
- **No issuer EPS TTM on non-SEC listings.** Yahoo trailing EPS below the issuer's newest-period basic EPS is withheld; at or above it publishes with an unreconciled `issuer-report` gap (`0097.KL` `039b7681`: Yahoo 0.16 vs the 13.45 sen 9M YTD figure; trailing PE 63.25 still publishes). An issuer TTM (FY + YTD − prior YTD, hand-derived 15.89 sen from a 7.04 sen FY2025) needs the prior FY report, which the web gather does not fetch; it is a basic per-share approximation over differing weighted share counts.
- **No peer comps on non-SEC listings.** Target valuation needs a USD quote (first gate, `valuation.ts`) and a `sec-edgar` item, so comps are skipped with "target valuation unavailable" before peer sourcing. Past that gate, peers come only from US ticker mappings, the US subject registry, or SEC-directory-checked proposals, and comp fundamentals from SEC companyfacts.
- **Profiled-listing range baselines stop at a weekday gap.** On an Exchange Profile listing the sessions before the scoring anchor are counted only when at most a weekend separates the reference close from the run date (a Monday–Friday week is assumed); a weekday between, such as a Bursa holiday or a stale close, omits the range baseline with a `forecast-baseline` gap. Counting it needs provider-observed sessions or a per-exchange calendar.
- **Issuer IR pages are not report hosts.** Only the Exchange Profile hosts count (ADR 0006). Web search can surface an issuer-domain page (`vitrox.com` in `3f1aa431`), but non-SEC runs have no declared issuer domain to classify it as primary.

## Ruled out

Each was measured; don't reinvestigate without new evidence.

- **Note-schedule debt containment:** settles 0 instants (2026-11-04).
- **Calc-linkbase proof for catch-all rows:** would publish no zero, because every footed decomposition ends in an unprovable `Other*` leaf (2026-11-04; OLED shows the hazard).
- **Model reading of the debt note:** cannot prove containment, since title, magnitude and bound checks pass even when part of the borrowing sits in a non-debt row.
- **Discontinued-financing-flow rule for CLFD debt scope:** reverted (never on master; no financing-flow concept in `sec-debt*.ts`). A flow is not a balance, and the rule over-fires (HLIT).
- **Amount equality as containment:** never proves it.
- **Fetching older filings' calc linkbases for capex/D&A:** 31 capex periods across 26 filings, ~7 real flips (all past periods), ~3 requests per filing at 1 req/s and 3 fixture recaptures; D&A gains notes only (2026-11-05). The zero-request debt-face piggyback ships instead.
- **GPN and Vistance continuing OCF:** neither filing states the split (checked 2026-11-04).
- **Catalog derivations for typed figures:** over the newest 60 runs only 4 of 1215 typed figures (segment revenue YoY) are exactly derivable from catalog rows; typed margins are for quarters the catalog lacks, since releases precede the 10-Q (2026-11-09; method not saved in the repo, #184's body gives a different exact-match count, 62 of 1046). Most typed figures are issuer-release and web values, the domain of verified web figures.
