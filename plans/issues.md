## Run cost and citations

- **Compact amounts outside the run's own currency read as entity names, so an uncited figure can pass the prune.** `isNumericClaim` (`post-synthesis-audit.ts`) counts a name-shaped token ("R500", "Myr500") as a figure only when its prefix is the run's Quote or Reporting Currency code or its CLDR "en" letter symbol. Still read as names: other currencies ("Zar500" or "Aed500" on a USD run), local abbreviations CLDR "en" lacks ("Ksh500" on a KES run, "Dhs500" on an AED run), and any run with neither currency resolved. The reverse also holds: a same-currency product name ("Cloudflare R2" on a ZAR run) counts as a figure. Fiscal-period tokens are stripped first, so "Q2" on a GTQ run (symbol "Q") is never counted as a figure.
- **KEEL conditional forecast rejected by the parser.** The second leg was anchored at +5 instead of 0 (`d8ee4c0c`), costing one repair call.
- **Model forecasts restate the steering band (unproven defect).** In the 2026-11-05 batch 6 of 7 model range forecasts copy the +10 reference band at p 0.34–0.40 against a 0.34 base rate; 16 of 21 predictions are near base rate. ORCL `b685f6d4` copies its band at p 0.34, and 0097.KL has copied the same [9.33, 10.98] band in three consecutive runs (p 0.38, 0.32, 0.32), where the non-US fallback `RANGE_REFERENCE_OUTSIDE_PROBABILITY` 0.32 is the stated base rate. Prompt guidance stays inside ADR 0003; dropping the anchor would amend it. Needs resolved Paired Skill, not a prompt change.
- **Non-US close due dates run on the US calendar.** `closeDueDate` (`policy.ts`, via `resolutionDate`) counts NYSE sessions for every equity, so a Bursa holiday inside the window fires the due date a session early and burns one of the four observation attempts (`MAX_OBSERVATION_FAILURES`); the 1/3/7-day retries absorb it. The 2026-11-06 0097.KL `grid-range-1` rows already show one burned attempt ("observation unavailable"; calendar vs Yahoo lag not separable); their `grid-range-5` rows are due 11-13 on NYSE vs 11-16 on Bursa (closed 11-09), so the 11-13 score pass is the proof. Fix with an exchange calendar on `ExchangeProfile`.
- **SEC excerpts.** 5.5–8.5k chars per 10-K/10-Q plus 3k per 8-K (ORCL `b685f6d4`: 20k in total) reach web-subject-profile, specialist, instrument-evidence, market-behavior, critique and synthesis in full; all of them cite the prose (market-behavior cited only the 10-Q there). A cut would have to drop sections no stage cites, and which sections those are is unchecked.
- **Pre-quote Web Subject Profiles regenerate once.** AAPL (4) and OUST (2 failing figures) profiles still predate `figureQuotes`, so their next deep run pays one profile stage; AMD, ORCL and 0097.KL regenerated, and AMD reused the new profile on 2026-11-09. `trace.json:webSubjectProfileReuse` records the reuse decision and its reason, but not why each skipped candidate was refused (the lookup is a replay-recorded value; reconstruct by replaying `screenReusedWebSubjectProfile`). Quote compliance of live stages is unmeasured; check with `eval-deep.ts --live-stages` before relying on it.
- **Peer-median audit gets a duplicate description-only clause.** `peerMedianAuditClauses` (`finalize-synthesis.ts`) already feeds `name: description` per scenario, but `claimsForReport` (`report-integrity-audit.ts`) also emits the bare description, deduped only when identical. Dropping it changes recorded clause lists, so do it with the next cassette recapture.
- **Final-synthesis replay inputs keep their recording commit's upstream state.** `62ba6299` (0097.KL) predates #154, so its price history is empty and grid and baselines drop out; `0693b9fc` (ORCL brief) priorStages cite a prior run's 8-K id, which #186 now strips at prompt time. Use the 2026-11-09 captures (`039b7681`, `b685f6d4`) instead; their raw `historicalContext` still carries prior-run ids by design.
- **Catalog figure hints match on the rounded display value.** 0097.KL quote MYR 10.12 matched `sma50` 10.116 in 3 of 3 live samples (`data/evals/hint23-live-62ba6299`); the model kept the text each time. Exact-value matching would also drop real rounded ratios (ORCL 31.6%), so it stays.

## Withheld correctly (coverage gaps)

Each of these publishes a declared Source Gap. Recover one only under the rule at the top.

- **TTM rows with a filed count but no derived one stay withheld.** 49 rows at 21 issuers (2026-11-10 sweep) have a filed diluted count at the TTM end but publish none: 46 fail the old NI / EPS gate kept as a shortcut, and ALLT 2024-06-30/2025-06-30 (3-month count in another 6-K than the 6-month EPS) and SILC 2018-06-30 (count first tagged 2019-08-28) withhold on pairing and date. - **Annual periods with no filed diluted count are withheld** (9 periods: TAYD FY2023–26, GOOGL FY2018–19, GPN FY2016, INVZ FY2020–21); NI / diluted EPS no longer stands in.
- **A null close before the newest bar still rejects the whole split-adjusted history.** Only a null newest close is dropped (as an unverified session); an earlier one would shift scoring's session count. Seen once, in a `yahoo-verified-chart` payload (NBIS 2026-08-11, cache 2026-08-12) followed by an in-progress bar; recovering it needs a per-use rule, not a parser drop.
- **No issuer EPS TTM on non-SEC listings.** Yahoo trailing EPS below the issuer's newest-period basic EPS is withheld; at or above it publishes with an unreconciled `issuer-report` gap (`0097.KL` `039b7681`: Yahoo 0.16 vs the 13.45 sen 9M YTD figure; trailing PE 63.25 still publishes). An issuer TTM (FY + YTD − prior YTD, hand-derived 15.89 sen from a 7.04 sen FY2025) needs the prior FY report, which the web gather does not fetch; it is a basic per-share approximation over differing weighted share counts.
- **No peer comps on non-SEC listings.** Target valuation needs a USD quote (first gate, `valuation.ts`) and a `sec-edgar` item, so comps are skipped with "target valuation unavailable" before peer sourcing. Past that gate, peers come only from US ticker mappings, the US subject registry, or SEC-directory-checked proposals, and comp fundamentals from SEC companyfacts.
- **Profiled-listing range baselines stop at a weekday gap.** On an Exchange Profile listing the sessions before the scoring anchor are counted only when at most a weekend separates the reference close from the run date (a Monday–Friday week is assumed); a weekday between, such as a Bursa holiday or a stale close, omits the range baseline with a `forecast-baseline` gap. Counting it needs provider-observed sessions or a per-exchange calendar.
- **Issuer IR pages are not report hosts.** Only the Exchange Profile hosts count (ADR 0006). Web search can surface an issuer-domain page (`vitrox.com` in `3f1aa431`), but non-SEC runs have no declared issuer domain to classify it as primary.
